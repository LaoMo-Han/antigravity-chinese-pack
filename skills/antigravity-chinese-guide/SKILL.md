# Google Antigravity 官方中文完全指南

Google Antigravity 是以 AI 智能体为核心的现代化全栈开发平台。无论您使用的是 Antigravity 2.0 独立桌面端、Antigravity IDE 还是命令行工具，本指南都能帮助您迅速掌握其核心工作流。

---

## 1. 软件界面与核心模块 (Antigravity 2.0)

### 界面主要区域

1. **左侧导航栏 (Left Sidebar)**：
   - **新建对话 (New Conversation)**：发起全新的智能体对话与任务。
   - **项目管理 (Projects)**：浏览并切换本地代码库工作区。
   - **计划与自动化任务 (Automations / Scheduled Tasks)**：管理定时运行的后台 Cron 任务或一次性延时任务。
   - **自定义配置与扩展 (Customizations)**：管理插件 (Plugins)、技能 (Skills)、规则 (Rules) 及 MCP 服务器。
   - **系统设置 (Settings)**：配置模型偏好、权限策略与界面外观。
2. **中央对话画布 (Chat Canvas)**：
   - 主交互窗口，支持任务规划、实时工具调用回显、文件差异预览与任务流跟踪。
   - **斜杠指令 (`/`)**：输入 `/` 可调出快捷功能菜单。
   - **上下文引用 (`@`)**：输入 `@` 可直接附加工作区文件、文件夹、终端会话、历史记录或 MCP 资源。
   - **多模态媒体拖拽**：支持直接拖拽图片、设计稿到对话框中供智能体分析。
3. **辅助面板 (Auxiliary Pane)**：
   - 包含子智能体监控 (Subagents)、后台任务状态 (Background Tasks)、生成制品 (Artifacts)、文件变动对比 (Files Changed) 和内置终端 (Terminals)。

## 2. 常用斜杠指令速查 (Slash Commands)

| 指令 | 中文名称 | 适用场景与功能 |
| :--- | :--- | :--- |
| `/goal` | 深度目标达成 | 适合复杂或长时任务，智能体将竭尽全力反复自检直至完全达成目标。 |
| `/plan` | 步骤化规划 | 在正式改动代码前，先输出详尽的架构与执行计划供审阅。 |
| `/browser` | 网页与浏览器交互 | 启动内置浏览器智能体，进行网页自动化操作、UI 审查或数据采集。 |
| `/boost` | 深度多维度开发 | 启动高级多重视角深度思考与代码验证，适合高难度架构重构。 |
| `/teamwork` | 团队多智能体协作 | 启动多智能体协作网络，分工并行处理多个模块。 |
| `/compact` | 上下文压缩 | 当会话历史过长时压缩上下文，节省 Token 窗口。 |
| `/schedule` | 定时任务调度 | 设置定时或周期性后台执行任务。 |
| `/grill-me` | 需求对齐与深度访谈 | 由智能体向您逐项提问确认方案设计与边界细节。 |
| `/learn` | 经验沉淀与学习 | 将本次会话沉淀的最佳实践或修复规则持久化保存。 |

## 3. 快捷键指南

- `Ctrl + D` / `Cmd + D`：中止当前智能体运行 / 取消任务。
- `Ctrl + I` / `Cmd + I`：代码行内指令（在代码编辑器中高亮代码后就地调用 AI 重构或解释）。
- `Tab`：补全智能体推荐代码或跳至预测游标位置。
- `Ctrl + B` / `Cmd + B`：展开或折叠侧边栏。

---

## 4. 权限与安全等级

在界面底部可随时调整智能体权限预设：
- **Turbo (极速模式)**：自动执行大部分无害工具与终端指令，速度最快。
- **Proceed in Sandbox (沙箱运行)**：在隔离沙箱环境中执行命令，保障宿主系统安全。
- **Request Review (严格确认)**：在执行关键终端命令前均需您手动点击确认。
